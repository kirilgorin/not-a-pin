# Not a Pin

Keep Iconize icons visible in Obsidian tabs when Obsidian rebuilds a tab header, such as after pinning or unpinning a note.

## Requirements

- Obsidian 1.5.0 or later
- [Iconize](https://github.com/FlorianWoelki/obsidian-iconize)

## Install

Install **Not a Pin** from Obsidian's Community plugins directory and enable it. Keep Iconize enabled and turn on **Toggle icon in tabs** in Iconize settings.

The plugin watches tab-header changes and reapplies the icon currently assigned to each note in Iconize. It does not change Iconize's saved icon data.
